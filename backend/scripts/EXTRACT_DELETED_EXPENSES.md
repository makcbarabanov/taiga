# ВОССТАНОВЛЕНИЕ УДАЛЁННЫХ РАСХОДОВ

## 🚨 КРИТИЧЕСКАЯ СИТУАЦИЯ

Удалено примерно **100 записей расходов**. Логирование PostgreSQL включено (`log_statement = all`), значит данные должны быть в логах.

## 📋 ШАГИ ДЛЯ ВОССТАНОВЛЕНИЯ

### 1. Подключитесь к серверу БД

```bash
ssh user@83.217.220.97
```

### 2. Найдите логи PostgreSQL

Логи обычно находятся в одном из мест:
- `/var/lib/postgresql/*/data/pg_log`
- `/var/log/postgresql/`
- `/var/lib/pgsql/*/data/pg_log`

### 3. Найдите DELETE запросы

```bash
# Перейдите в директорию с логами
cd /var/lib/postgresql/*/data/pg_log

# Или
cd /var/log/postgresql/

# Найдите последние DELETE запросы
grep -i "DELETE FROM taiga.expenses" *.log | tail -100

# Или посмотрите последние логи
ls -lt | head -5
tail -1000 postgresql-*.log | grep -i "DELETE FROM taiga.expenses"
```

### 4. Извлеките данные из логов

В логах должны быть строки вида:
```
DELETE FROM taiga.expenses WHERE id = 32
```

Или если логирование детальное, могут быть данные удалённых записей.

### 5. Восстановите данные

Используйте скрипт `restore-expense.js` для каждого удалённого расхода:

```bash
cd E:\Forge\_projects\taiga\backend
node scripts/restore-expense.js <id> <date> <amount> <category_id> [project_id] [subcategory] [comment]
```

Или используйте массовое восстановление через `bulk-restore-expenses.js`:

1. Создайте файл `restore-data.json`:
```json
[
  {
    "id": 32,
    "date": "2025-12-01",
    "amount": 1000,
    "category_id": 1,
    "project_id": 1,
    "subcategory": "Подкатегория",
    "comment": "Комментарий"
  }
]
```

2. Запустите восстановление:
```bash
node scripts/bulk-restore-expenses.js restore-data.json
```
