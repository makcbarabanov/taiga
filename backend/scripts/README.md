# Скрипты для работы с системой классификации расходов

## classify-expense.js

Скрипт для ручного разбора расходов и обучения системы классификации.

### Использование

#### Интерактивный режим (рекомендуется)

```bash
npm run classify
```

или

```bash
node scripts/classify-expense.js
```

В этом режиме можно последовательно вводить расходы, система будет:
1. Пытаться определить категорию автоматически
2. Если не получается - показывать список категорий
3. После выбора категории автоматически создавать правило

#### Командная строка

```bash
npm run classify "текст расхода"
```

Например:
```bash
npm run classify "50х150х6000"
npm run classify "Барабанов М.В."
npm run classify "Бензин для генератора"
```

### Пример работы

```
📝 Введите текст расхода: 50х150х6000

✅ Найдена категория: Мат (Материалы)
📋 Правило: Материал по шаблону размеров (например, 50х150х6000)
```

Если категория не определена:

```
📝 Введите текст расхода: Что-то непонятное

❌ Категория не определена автоматически

📚 Доступные категории:
  1. Инстр - Инструменты (ID: 5)
  2. Мат - Материалы (ID: 1)
  3. Маржа - Маржа (ID: 7)
  4. Накл - Накладные (ID: 4)
  5. Расх - Расход (ID: 6)
  6. ТЗР - Транспортно-заготовительные расходы (ID: 3)
  7. ФОТ - Фонд оплаты труда (зарплаты) (ID: 2)

Выберите номер категории или введите ID: 2

✅ Правило создано!
   Тип: keyword, Паттерн: Что-то непонятное
```

### Завершение работы

В интерактивном режиме введите `выход` или `exit` для завершения.
