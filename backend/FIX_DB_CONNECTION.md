# 🔧 Исправление ошибки подключения к БД

## Проблема
```
error: password authentication failed for user "marabot"
```

## Решение

### Вариант 1: Проверить пароль в DBeaver

1. Откройте DBeaver
2. Проверьте подключение к базе данных
3. Посмотрите, какой пароль используется там
4. Обновите пароль в файле `.env` в папке `backend`

### Вариант 2: Обновить пароль в .env

Откройте файл `E:\Forge\_projects\taiga\backend\.env` и проверьте:

```env
DB_HOST=83.217.220.97
DB_PORT=5432
DB_NAME=default_db
DB_USER=marabot
DB_PASSWORD=2nix8#mN&Er5tR  # Проверьте этот пароль!
DB_SCHEMA=taiga

PORT=3000  # Исправьте на 3000 (было 30)
```

### Вариант 3: Экранирование специальных символов

Если пароль содержит специальные символы (`#`, `&`), может потребоваться экранирование или кавычки.

Попробуйте в `.env`:
```env
DB_PASSWORD="2nix8#mN&Er5tR"
```

Или если это не поможет, проверьте правильность пароля в DBeaver.

### Вариант 4: Проверить подключение через psql

Попробуйте подключиться напрямую:
```bash
psql -h 83.217.220.97 -U marabot -d default_db
```

Введите пароль и проверьте, подключается ли.

---

**После исправления перезапустите сервер:**
```powershell
cd E:\Forge\_projects\taiga\backend
$env:PATH += ";C:\Program Files\nodejs\"
npm start
```
