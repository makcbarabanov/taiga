## 📋 Описание проекта

Проект Taiga - это система автоматизации финансового и процедурного учёта строительной компании. Система призвана заменить ручной учёт в Google Таблицах на автоматизированную веб-систему с базой данных PostgreSQL.

---

## 🎯 Текущая ситуация

### Что есть сейчас:

Финансовый и процедурный учёт ведётся в Google Таблицах в основной таблице **"Тайга 2023"** (год уже не актуален, будет переименован).

**Структура таблицы "Тайга 2023":**

1. **Рас (Расход)** - все расходы со всех объектов по всем категориям
2. **Дох (Доходы)** - все доходы от клиентов
3. **О (Объекты)** - база всех объектов с финансовой аналитикой:
   - Список всех объектов с именами клиентов (один клиент может иметь несколько объектов)
   - Прибыль по объекту (плановая, фактическая, разница)
   - План/факт/разница по доходам
   - План/факт/разница по расходам по категориям (материал, работа, ТЗР, накладные)
4. **Касса** - ежедневная сверка остатков денег (факт vs расчёт)
5. **Инст (Инструмент)** - справочник инструментов на балансе
6. **Маги (Магазины)** - справочник магазинов и поставщиков

### Порядок работы:

1. Заключается договор с клиентом на основе **СМЕТЫ**
2. Смета состоит из:
   - Стоимости материалов
   - Стоимости работ
   - ТЗР (транспортно-заготовительные расходы)
   - Накладные расходы
3. После заключения договора смета попадает в отдельную Google Таблицу (названную в честь клиента)
4. Приобретается материал, расходы заносятся в "Тайга 2023"
5. Ежедневно ведётся учёт работы в Журнале
6. Автоматически формируется график работы и процент выполнения

## 📊 Структура веб-интерфейса

### Этап 1: Повторение структуры "Тайга"

1. **Объекты** (`objects.html`)
   - Автоматическое обновление из БД
   - Кнопка "Добавить объект"
   - Кнопка "Добавить клиента" (объекты всегда связаны с клиентами)

2. **Доходы** (`income.html`)
   - Добавление через модальное окно

3. **Расходы** (`expenses.html`)
   - **Тестирование:** редактируемые ячейки (как в Google Sheets)
   - Если работает корректно - оставляем
   - При ошибках - переходим к модальному окну
   - Возможность загрузить PDF или XLS файл

4. **Касса** (`cash.html`)
   - Ежедневный учёт финансов
   - Ручной ввод фактического остатка
   - Сравнение с расчётной суммой (Доходы - Расходы + начальный остаток)
   - Начальный остаток - динамический (будет указан позже)

5. **Перенос данных** (`import.html`)
   - Импорт данных из "Тайга 2023.xls" в БД
   - Отображение данных в `taiga.html`

### Этап 2: Страница текущего клиента

**Стеклянный Феруз 5х8 гостевой** (`client-feruz.html`)

Структура страницы:
1. **Стат** - статистика по дням (план/факт готовности)
2. **Работы** - опись работ с прогрессом
3. **Снаб** - ведомость материалов (смета/факт/разница)
4. **Журнал** - журнал ведения работ
5. **Табель** - автоматически из журнала

## 🔄 Логика работы системы

### Взаимосвязь таблиц:

1. **При внесении расхода в "Тайга 2023 → Рас":**
   - Указывается: Клиент, Объект, Категория, Подкатегория, Количество, Цена, Стоимость, Магазин
   - Система автоматически находит соответствующий объект клиента
   - Обновляет раздел "СНАБ" в таблице клиента:
     - Заполняет колонку "Факт" (количество, цена, стоимость)
     - Рассчитывает разницу (Смета - Факт)
     - Обновляет аналитику (приобретено товаров, осталось потратить и т.д.)

2. **Справочник соответствий товаров:**
   - Создаётся совместно (пользователь + система)
   - При новом товаре из чека:
     - Если товар найден в смете → добавляется в ФАКТ
     - Если товар не найден → добавляется только в ФАКТ, СМЕТА остаётся пустой

3. **Обработка чеков:**
   - Пользователь использует сторонние сервисы для распознавания чеков
   - Сервисы конвертируют в PDF/XLS
   - Система обрабатывает файлы и извлекает данные
   - Автоматическое сопоставление с сметой через справочник соответствий

## 🔧 Технические детали

### Формат ввода расходов:

**Текущий формат в "Тайга 2023 → Рас":**
```
Дата | Мес | Год | Категория | Подкатегория | Ед. изм. | Кол-во | Цена | Ст-сть | Клиент | Объект | Раздел | Кошелёк | Маг
```

**Пример:**
```
25.01.2025 | | | Мат | Автомат 6а | шт | 2 | 303 | 606 | Ирезепов Алексей | М.Баня 6х5 | | | Петрович
```

### Формат раздела "СНАБ" в таблице клиента:

```
Категория | Наименование | Ед. изм | Смета (кол-во, цена, ст-сть) | Факт (кол-во, цена, ст-сть) | Разница
```

**Аналитика:**
- Всего товаров
- Сметная стоимость
- Приобретено товаров
- Снабжение (%)
- Экономия
- Осталось потратить
