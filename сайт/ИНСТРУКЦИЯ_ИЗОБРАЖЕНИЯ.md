## 🎯 Где взять изображения:

### Вариант 1: Реальные фотографии (ЛУЧШИЙ)
- Сделайте фото ваших готовых домов
- Профессиональная фотосъёмка производства
- Фото довольных клиентов с домами

### Вариант 2: Stock-фотографии (временно)
Бесплатные источники:
- **Unsplash** (unsplash.com) - высокое качество
- **Pexels** (pexels.com) - бесплатно для коммерции
- **Pixabay** (pixabay.com) - большой выбор

Поисковые запросы:
- "modular house"
- "prefab home"
- "modern cabin"
- "tiny house"
- "wooden house exterior"

### Вариант 3: AI-генерация
Можно использовать:
- Midjourney
- DALL-E
- Stable Diffusion

Промпт: "modern modular wooden house, exterior view, professional photography, natural lighting, forest background"

## 🔧 Как оптимизировать изображения:

### Онлайн-инструменты:
1. **TinyPNG** (tinypng.com) - сжатие до 70%
2. **Squoosh** (squoosh.app) - от Google
3. **Compressor.io** - пакетная обработка

### Десктоп-программы:
- **Photoshop** - экспорт для веба
- **GIMP** (бесплатно)
- **XnConvert** (пакетная обработка)

### Настройки:
- Формат: JPG, качество 80-85%
- Размер: 1200x800 px
- Вес: 100-200 KB

## 📥 Как добавить изображения:

### Шаг 1: Подготовка
```
1. Скачайте/сделайте фотографии
2. Переименуйте согласно списку выше
3. Оптимизируйте размер и вес
```

### Шаг 2: Размещение
```
1. Откройте папку проекта: E:\Island\projects\taiga\images\
2. Скопируйте файлы в соответствующие подпапки:
   - Дома → images/houses/
   - Производство → images/factory/
   - Процесс → images/process/
   - Портфолио → images/portfolio/
```

### Шаг 3: Проверка
```
1. Откройте index.html в браузере
2. Перейдите в каталог
3. Обновите страницу (Ctrl+F5)
4. Убедитесь, что изображения загрузились
```
