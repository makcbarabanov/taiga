# 🎨 Изображения для главного слайдера

## 📋 Нужны 3 изображения:

1. **slide-1.jpg** - Основное фото (красивый дом в лесу/на природе)
2. **slide-2.jpg** - Второе фото (другой ракурс или модель дома)
3. **slide-3.jpg** - Третье фото (интерьер или процесс производства)

## 📐 Требования:

- **Формат:** JPG
- **Размер:** 1920 x 1080 px (Full HD) или 2560 x 1440 px (2K)
- **Соотношение:** 16:9 (горизонтальное)
- **Вес:** 300-500 KB (сжатые)
- **Качество:** Высокое, профессиональное фото

### 🎨 Что искать:

**Для slide-1 (главное фото):**
- Красивый модульный дом на природе

## ⚙️ Оптимизация изображений:

После скачивания обязательно сожмите:

### Онлайн-инструменты:
1. **TinyPNG** - https://tinypng.com
   - Перетащите файл
   - Скачайте сжатый (экономит 60-70%)

2. **Squoosh** - https://squoosh.app
   - От Google
   - Настройте качество 80-85%

3. **Compressor.io** - https://compressor.io
   - Пакетная обработка

### Настройки сжатия:
- JPG качество: 80-85%
- Размер: 1920x1080 px
- Целевой вес: 300-500 KB

## 📥 Как добавить:

1. Скачайте 3 изображения с Unsplash/Pexels
2. Переименуйте в: `slide-1.jpg`, `slide-2.jpg`, `slide-3.jpg`
3. Оптимизируйте через TinyPNG
4. Скопируйте в эту папку: `E:\Island\projects\taiga\images\hero\`
5. Обновите главную страницу в браузере (Ctrl+F5)

1. **Выбирайте фото с хорошей композицией** - оставьте место слева/сверху для текста
2. **Не слишком яркие** - чтобы белый текст был читаем
3. **В одном стиле** - все 3 фото должны гармонировать
4. **Без текста** - не используйте фото с надписями
5. **Высокое разрешение** - минимум Full HD (1920x1080)
