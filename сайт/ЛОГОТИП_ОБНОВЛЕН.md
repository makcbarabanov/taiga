## 🔧 Как изменить (если нужно):

### Изменить размер:
Откройте `assets/css/styles.css`, найдите:
```css
.logo-main {
    font-size: 32px;  ← измените на 36px или 28px
}
```

### Изменить цвет:
```css
.logo-main {
    color: #059669;  ← измените на другой цвет
}
```

**Примеры цветов:**
- Синий: `#0284c7`
- Чёрный: `#111827`
- Серый: `#374151`

### Изменить текст:
Откройте любой HTML файл, найдите:
```html
<span class="logo-main">TAIGA</span>
<span class="logo-sub">строительная компания</span>
```
И измените текст.
