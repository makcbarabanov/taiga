# 🔔 Напоминание: Сохранение в GitHub

**Важно:** Регулярно сохранять проект Тайга в GitHub!

## 📋 Чек-лист перед завершением работы:

- [ ] Проверить изменения: `git status`
- [ ] Добавить все изменения: `git add --all`
- [ ] Создать коммит: `git commit -m "описание изменений"`
- [ ] Отправить на GitHub: `git push origin master`
