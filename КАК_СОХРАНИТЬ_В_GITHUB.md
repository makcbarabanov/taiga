# 📚 Как сохранить изменения в GitHub

## 🔍 Разница между Git и GitHub

**Git** = система контроля версий (локально на твоём компьютере)
- Отслеживает изменения в файлах
- Создаёт "снимки" (коммиты) твоей работы
- Хранит историю изменений

**GitHub** = облачный сервис для хранения Git-репозиториев
- Хранит твой код в интернете (резервная копия!)
- Позволяет работать в команде
- Можно смотреть код в браузере

**Простыми словами:**
- **Git** = фотоаппарат (делает снимки твоей работы)
- **GitHub** = облако (хранит эти снимки в интернете)

---

## ✅ Три простых шага для сохранения

### Шаг 1: Проверить, что изменилось
```powershell
cd E:\Forge\_projects\taiga
git status
```

**Что показывает:**
- `modified:` — изменённые файлы
- `Untracked files:` — новые файлы, которые ещё не добавлены

---

### Шаг 2: Добавить все изменения
```powershell
git add --all
```

**Что делает:** Готовит все изменения к сохранению (добавляет в "staging area")

---

### Шаг 3: Сохранить с описанием
```powershell
git commit -m "Описание того, что сделал"
```

**Примеры описаний:**
- `"Добавлен табель работ"`
- `"Исправлена ошибка в журнале"`
- `"Обновлена документация"`
- `"121225 - работа над табелем"` (дата)

---

### Шаг 4: Отправить на GitHub
```powershell
git push origin taiga
```

**Что делает:** Отправляет твои изменения на GitHub (в облако)

---

## 🚀 Полная команда (все шаги сразу)

```powershell
cd E:\Forge\_projects\taiga
git status                    # Проверить изменения
git add --all                 # Добавить всё
git commit -m "Описание"      # Сохранить
git push origin taiga         # Отправить на GitHub
```

---

## 💡 Полезные команды

### Посмотреть историю коммитов
```powershell
git log --oneline
```

### Отменить последний коммит (если ошибся)
```powershell
git reset --soft HEAD~1
```

### Посмотреть, что изменилось в файле
```powershell
git diff имя_файла
```

---

## ⚠️ Важно помнить

1. **Коммить часто** — лучше много маленьких коммитов, чем один огромный
2. **Писать понятные описания** — чтобы потом понять, что делал
3. **Пушить каждый день** — это резервная копия в облаке!
4. **Проверять статус** — перед коммитом всегда делай `git status`

---

## 🆘 Если что-то пошло не так

### Ошибка: "nothing to commit"
**Значит:** Все изменения уже сохранены. Всё ОК!

### Ошибка: "authentication failed"
**Решение:** Нужно авторизоваться в GitHub (использовать Personal Access Token)

### Ошибка: "failed to push"
**Решение:** Сначала скачать изменения: `git pull origin taiga`, затем снова `git push origin taiga`
