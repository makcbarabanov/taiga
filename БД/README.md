# 🐯 Проект Taiga

Проект Taiga - новый проект, не связанный с марафоном полезных привычек.

## 📁 Структура проекта

```
taiga/
├── README.md                    # Этот файл
├── DATABASE_SETUP.md           # Подробная инструкция по работе с БД
├── create_taiga_schema.sql     # SQL-скрипт для создания схемы taiga
└── example_table_template.sql  # Шаблон для создания таблиц
```

## 🚀 Быстрый старт

### 1. Создание схемы в базе данных

Выполни SQL-скрипт `create_taiga_schema.sql` в DBeaver или через psql:

```bash
psql -h 83.217.220.97 -U marabot -d default_db -f create_taiga_schema.sql
```

### 2. Создание первой таблицы

Используй `example_table_template.sql` как основу для своих таблиц.

### 3. Подробная документация

Читай `DATABASE_SETUP.md` для детальной информации о:
- Подключении к базе данных
- Создании схем и таблиц
- Работе с данными
- Полезных командах
