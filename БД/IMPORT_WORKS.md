## ✅ Что делает скрипт

1. **Читает CSV файл:** `Экспорт/Стеклянный Феруз 5х8 гостевой - Работы (копия).csv`

2. **Определяет:**
   - Раздел работы (из префикса: "Основа", "Стены" и т.д.)
   - Этап работы (из вручную заданного маппинга)
   - Вид работы (удаляет префикс раздела)

3. **Создаёт/обновляет:**
   - Справочники (если чего-то не хватает)
   - Записи в `project_works`

4. **Обрабатывает:**
   - Пустые строки и разделители " - " → пропускает
   - Работы без количества → `quantity = 0`

---

## 📊 Структура данных

### Справочники:

- **work_stages** (Этапы):
  - Тёплый контур
  - Отделка

- **work_sections** (Разделы):
  - Фундамент, Подсобка, Основа, Стены, Окна, Двери
  - Веранда, Потолок, СанУзел (СУ), Электрика (Эл)
  - Сантехника (Сантех), Вентиляция (ВЕНТ), Общестрой

- **work_types** (Виды работ):
  - Создаётся автоматически при импорте
  - Названия без префикса раздела

### Таблица project_works:

- `stage_id` → `work_stages(id)`
- `section_id` → `work_sections(id)`
- `work_type_id` → `work_types(id)`
- `quantity` — количество (0 если не указано)
- `progress_percent` — вычисляется из журнала автоматически

## 🔍 Проверка результата

После импорта проверьте:

```sql
-- Все работы проекта
SELECT * FROM taiga.v_project_works_full 
WHERE project_id = (SELECT id FROM taiga.projects WHERE name = '5х8 гостевой')
ORDER BY sort_order;

-- Статистика
SELECT 
    ws.name AS этап,
    COUNT(*) AS количество_работ,
    SUM(pw.quantity) AS общий_объём
FROM taiga.project_works pw
JOIN taiga.work_stages ws ON pw.stage_id = ws.id
WHERE pw.project_id = (SELECT id FROM taiga.projects WHERE name = '5х8 гостевой')
GROUP BY ws.name;
```

---

## ⚠️ Важные замечания

1. **Этапы:** Задаются вручную в коде скрипта (маппинг `STAGE_MAPPING`)

2. **Работы без количества:** Сохраняются с `quantity = 0` (в UI выделять слабокрасным)

3. **Прогресс:** Вычисляется автоматически из `project_journal` через триггер

4. **Полное название:** Получается из представления `v_project_works_full`:
   ```sql
   SELECT work_name FROM taiga.v_project_works_full;
   -- Результат: "Основа - Утепление 200мм"
   ```
