📝 Правила записи расходов по типам материалов

Этот файл содержит правила форматирования расходов для разных типов материалов. Эти правила используются при добавлении расходов в режиме обучения ("expense learning mode").

Важно: Эти правила применяются после определения категории расхода. Они описывают, как правильно заполнять поля "Подкатегория", "Единица измерения", "Количество" и "Комментарий" для разных типов материалов.

📊 Статистика обучения

Текущая точность определения категорий: ~10% (требуется обучение)

Метод подсчёта: Учитываются только расходы, где пользователь подтвердил категорию коротким ответом "да" или "верно" на первый вопрос о категории, без дополнительных уточняющих вопросов от системы.

Последняя сессия (2025-12-11):

  • Всего расходов обработано: 10
  • Определено без уточнений: ~1 ✅ (БЕЛТЕРМО - "категория верна")
  • Потребовали уточнений: ~9 ❓
  • Точность без уточнений: ~10%

История сессий:

  • 2025-12-11: ~1/10 (~10%) - большинство расходов потребовали уточнений
  • Цель: 100% точность без уточняющих вопросов

Критерий завершения обучения:

  • ✅ 3 раза подряд все расходы определены на 100% без уточняющих вопросов
  • ✅ Нет ошибок классификации
  • ✅ Система не задаёт уточняющих вопросов

🎯 Правила определения категорий расходов

1. Маржа (личные деньги Макса)

КРИТИЧЕСКОЕ ПРАВИЛО:

  • Категория: Маржа
  • Подкатегория: ВСЕГДА "Барабанов М.В." (единственная подкатегория для Маржи)
  • Комментарий: ОБЯЗАТЕЛЬНО указывать, на что потрачены деньги (например: "массаж", "хозтовары (шапка, задярка) Лента", "абонплата за cursor")
  • Ключевые слова: "Макс", "Барабанов", "М.В."

Примеры:

Категория: Маржа
Подкатегория: Барабанов М.В.
Комментарий: массаж
Сумма: 250₽

⚠️ ВАЖНО: Маржа НЕ используется для зарплаты Макса за работу. Для зарплаты используется категория "ФОТ".

2. ФОТ (фонд оплаты труда)

Правило:

  • Категория: ФОТ
  • Подкатегория: Имя сотрудника (из справочника сотрудников со статусом "Работает")
  • Ключевые слова: "Жура", "Даня", "Балуев", "Сирожутдин", "Алексей", "Жасур", "Хуснидин", "Ринат", "Фуркат"

3. Материалы (Мат)

Правила определения:

  • Шаблон размеров: \d+[хxXХ]\d+[хxXХ]\d+ (например: 50х150х6000, 25х100х6000)
  • Ключевые слова: "м²", "м2", "кг", "шт" (в контексте материалов)
  • Специфичные материалы: "профлист", "профнастил", "муфта", "кабель", "провод", "штукатурка", "грунт", "шпаклевка", "эмаль", "герметик", "клей", "бетон", "гипс", "пенополистирол", "сетка", "профиль", "саморезы", "гвозди", "арматура", "проволока", "дюбель"

4. ТЗР (транспортно-заготовительные расходы)

Правила:

  • Ключевые слова: "Доставка", "Аренда", "Газель", "Разгрузка материала"
  • ВАЖНО: Каршеринг (Делимобиль, Яндекс Драйв) для доставки материалов → ТЗР, не Накладные

5. Накладные расходы

Подкатегории:

  • Накладные - Бензин: "Бензин", "Татнефть", "Газпромнефть" (заправки)
  • Накладные - Продукты: "Продукты", "Пятёрочка", "Верный", "Магнит", "Дикси", "Шав24БМ", "Столовая"
  • Накладные - Транспорт: "Яндекс Драйв" (для личных поездок, не для доставки материалов)
  • Накладные - Метро: "Метро", "Местный транспорт"
  • Накладные - Связь: "Т-Мобайл", "Мобайл", "связь", "мобильная связь"
  • Накладные - Каршеринг: "Делимобиль" (только для личных поездок, не для доставки)

⚠️ ВАЖНО:

  • Делимобиль для доставки материалов → ТЗР
  • Делимобиль для личных поездок → Накладные - Каршеринг
  • Яндекс Драйв → Накладные - Транспорт (личные поездки)

6. Инструменты (Инструм)

Ключевые слова: "Перфоратор", "УШМ", "Пылесос", "домкрат", "Лопата", "Фонарь", "Прожектор"

7. Расходные материалы (Расход)

Ключевые слова: "мешки для мусора", "мешок", "шлифкруг", "шлифкруги", "Диск", "Нож", "Лезвия", "Круг абразивный"

🧱 БЕЛТЕРМО и Профлист

Правило записи:

  • Подкатегория: Указываем количество листов и полное описание материала
    • Пример: БЕЛТЕРМО, Топ, 200кг/м³, 2490×590×20мм Шип-паз 30 листов
    • Пример: Профлист МП-20/С-20 25 листов
  • Единица измерения: м² (квадратные метры)
  • Количество: Пересчитываем из листов в м²
  • Комментарий: Дополнительная информация (если нужна)

Обоснование:

  • Количество в листах нужно для проверки по месту
  • м² нужны для сравнения с конкурентными ценами

Пример:

Категория: Мат
Подкатегория: БЕЛТЕРМО, Топ, 200кг/м³, 2490×590×20мм Шип-паз 30 листов
Единица измерения: м²
Количество: 44.07 м²
Цена: 400₽/м²
Сумма: 17 640₽

🧱 Утеплители (минераловатные плиты)

Правило записи:

  • Подкатегория: Указываем количество упаковок и характеристики материала
    • Пример: Минплита Кнауф 100х610х1300, уп=0,634м3=6,34м2
    • В подкатегории указываем количество упаковок
  • Единица измерения: м³ (кубические метры)
  • Количество: Пересчитываем из упаковок в м³
  • Комментарий: Полное название материала из счёта (для алиасов в будущем)
    • Пример: Кнауф Инсулейшн ПРОФ 037, 100х610х1300, 0,634 м3/уп 6,34 м2/уп, 22уп

Обоснование:

  • Количество в упаковках нужно для проверки по месту
  • м³ нужны для сравнения с конкурентными ценами

Пример:

Категория: Мат
Подкатегория: Минплита Кнауф 100х610х1300, уп=0,634м3=6,34м2
Единица измерения: м³
Количество: 13.948 м³ (22 упаковки × 0,634 м³/уп)
Цена: 2 445₽/м³ (округлено от 2 444,79₽)
Сумма: 34 100₽
Комментарий: Кнауф Инсулейшн ПРОФ 037, 100х610х1300, 0,634 м3/уп 6,34 м2/уп, 22уп

📋 Общие принципы

  1. Подкатегория — краткое, но информативное описание материала с ключевыми характеристиками
  2. Единица измерения — выбирается для удобства сравнения цен (м², м³, шт и т.д.)
  3. Количество — всегда пересчитывается в выбранную единицу измерения
  4. Комментарий — полное название из счёта/накладной (для будущей системы алиасов)
  5. Форматирование цен:
    • Цены выше 1 рубля → без десятичных, округление в большую сторону
      • Пример: 2 444,79₽ → 2 445₽
      • Пример: 1 550,00₽ → 1 550₽
    • Цены до 1 рубля → с десятичными
      • Пример: 0,85₽ → 0,85₽
      • Пример: 0,50₽ → 0,50₽

🔄 Будущая система алиасов

В будущем планируется система алиасов, где:

  • Подкатегория — общее название товара (например, "Минплита Кнауф 100х610х1300")
  • Алиасы — различные названия одного и того же товара в разных магазинах
    • Пример: "Кнауф Инсулейшн ПРОФ 037" = "Кнауф ПРОФ 037" = "Кнауф Инсулейшн ПРОФ 037 (100х610х1300)"
  • Комментарий — сохраняет оригинальное название из счёта для сопоставления с алиасами

🎓 Процесс обучения

Этап 1: Получение чека с расходами

Пользователь отправляет "чек" с расходами (текст, список позиций). Система получает список расходов для классификации.

Этап 2: Определение категорий

Система анализирует каждую позицию расхода, использует существующие правила из expense_classification_rules и определяет предполагаемую категорию для каждой позиции.

Этап 3: Уточнение у пользователя

  • Система задаёт вопросы по одному (не все сразу)
  • Каждый вопрос имеет счётчик (1, 2, 3...)
  • Система спрашивает: "Правильно ли определена категория?"
  • Пользователь подтверждает или исправляет категорию
  • После подтверждения система переходит к следующему вопросу
  • При малейшем сомнении система задаёт уточняющие вопросы
  • Обсуждение происходит последовательно, пока не будет достигнуто 100% подтверждение всех расходов

Этап 4: Совершенствование правил

При обнаружении ошибки или нового случая система анализирует, почему была ошибка, создаёт новое правило или обновляет существующее, и сохраняет правило в expense_classification_rules для будущего использования.

Этап 5: Добавление расходов в Админку

После достижения 100% подтверждения всех расходов от пользователя система автоматически добавляет все расходы в Админку (таблица expenses). Каждый расход сохраняется с подтверждённой категорией и всеми данными.

⚠️ Критические правила (требуют особого внимания)

  1. Маржа: ВСЕГДА подкатегория "Барабанов М.В.", комментарий ОБЯЗАТЕЛЕН
  2. Делимобиль: Для доставки материалов → ТЗР, для личных поездок → Накладные
  3. Яндекс Драйв: Всегда Накладные - Транспорт (личные поездки)
  4. Метро: Всегда Накладные - Метро
  5. Продукты: Всегда Накладные - Продукты
